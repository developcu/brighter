# Brighter 1.0.0 — direct distribution

Small native menu bar utility for HDR brightness on compatible built-in XDR displays.

## Install

```sh
brew install --cask developcu/apps/brighter
```

Or download **Brighter.zip** from this release, unzip it and move Brighter.app to Applications.

Requires Apple silicon, macOS 14 or later and a compatible built-in XDR display. An M1 processor alone is insufficient: the 14-inch and 16-inch Apple silicon MacBook Pro models with Liquid Retina XDR displays are examples of compatible hardware. External displays and SDR-only displays are unsupported.

Open the sun icon in the menu bar, enable HDR boost and adjust its slider. Turn boost off or quit to return to normal brightness. Boost starts disabled on each launch. The factor is not a guaranteed measured increase in nits; brightness depends on system brightness, display headroom, power and temperature.

This ZIP is the existing verified direct release. The repository also contains subsequent English/Turkish UI and sandbox packaging work for App Store build 2; those additions are not in this prebuilt ZIP. The store build is distributed separately through Apple review.

The app uses an undocumented `multiply` compositor preset with Metal EDR. Apple can change that behavior in a future macOS update. This release has not been tested on every supported model or macOS version.
